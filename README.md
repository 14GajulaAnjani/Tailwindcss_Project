Greenwood Public Library Website

Landing page built with HTML and Tailwind CSS (CDN only, no custom fonts, no other frameworks).

How to run

Open index.html in a browser (internet needed for the Tailwind CDN). Keep the image files (1.png to 11.png) in the same folder as index.html.

Sections

Navbar, Hero, Sections grid, Gallery, Bento values, About columns, Membership, Testimonial, Contact, Events, Footer.

Features
Sticky navbar with backdrop-blur-md and animated underline links
Hover effects: image zoom, grayscale to colour, card colour changes
animate-pulse on the "Open Sat" badge
Responsive: 1 column on mobile, 2 on tablet, up to 4 on desktop
